I build tools for my own workflow — Arch, Wayland, and the servers behind them —
and ship production software for small businesses. 🐻‍❄️

### Tools I use every day

- **[dictado](https://github.com/Daf3r/dictado)** — hold a key, speak, release.
  Local voice dictation for Hyprland with whisper.cpp: ~440 ms, no cloud, no
  account. Documents every Wayland trap it hits along the way.
- **[pzget](https://github.com/Daf3r/pzget)** — keyboard-driven Arch/AUR
  installer. Searches packages by *what they do*, not what they're called, with
  Spanish keywords attached invisibly — so `reproductor` finds `mpv`.
- **[readme-generator](https://github.com/PolarZer0-dev/readme-generator)** —
  turn a form into a proper GitHub README, with live preview. No backend, runs
  entirely in your browser. → [try it](https://readme-generator.polarzero.dev)

### In production

Closed source, but deployed and in daily use:

- **GymNova** — management software for small gyms: members, plans, sales,
  expenses, reports and automated WhatsApp messaging. React 19 + Tauri 2 desktop
  shell over a Fastify + Prisma sidecar, with its own auto-update channel.
- **Casa Polar** — a private family app for coordinating remittances and shared
  finances. Next.js 16 + Postgres, running in Docker on a VPS behind Caddy and
  Cloudflare.
